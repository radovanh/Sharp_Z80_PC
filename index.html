// COVERAGE
01
PC-G815
Two independent HD61203-compatible controllers. Left panel ports 54h–57h, right panel 58h–5Bh. 144×32 pixel display, mirrored column geometry on each half.
02
PC-G850 Series
Single controller, 144×48 pixels. All commands through port 40h, status echo on 41h. No explicit busy polling — command echo used instead.
03
PC-E200 / E220
HD62202+HD61203 chip pair, 144×32 pixels. Ports 58h (cmd), 59h (busy), 5Ah (write), 5Bh (read). Dummy-read latch priming required.
04
Read-Modify-Write
All E-series and G815 controllers require a dummy read before the real read to prime the internal latch. Re-issue column address after read to prevent auto-increment corruption.
05
Column Mirror Geometry
Each controller panel drives two symmetric halves. Right half columns are addressed in reverse. G815 left ctrl: col = 119-X for X ≥ 60.
06
Pixel Byte Format
8 vertical pixels per byte. Bit 0 = topmost pixel in page. Page addressing: 0xB8 + page (page 0–3 for 32 rows, 0–5 for G850's 48 rows).
