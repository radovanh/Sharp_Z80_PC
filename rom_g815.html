PC-G815 ROM / BIOS Reference

IOCS (BIOS) call table for the Sharp PC-G815 and compatible machines (PC-E200, PC-G8xx series). All addresses are fixed ROM entry points callable from Z80 machine language. Sources: ver0.sakura.ne.jp IOCS table, akiyan.com analysis, game binary reverse engineering, z88dk source. Entries marked VERIFIED were confirmed by direct use in working code.

REGISTER CONVENTIONS: Position parameter: D = row (0–3 for G815), E = column (0–23 character columns). For graphics (BFD0h): D = pixel column (0–143), E = character row (0–3). Registers listed as "destroyed" must be saved by the caller if needed.

Display Routines

BE62h
Single Character Output
DISPLAY VERIFIED
// INPUT
A = ASCII character code
D = row (0–3)
E = column (0–23)
// OUTPUT
None
// DESTROYS
AF BC HL
Preserves: DE IX IY and alternates
Outputs one character to the screen at the specified row/column position. Used for single-character placement without scrolling.
Confirmed from game binary analysis — used before BFD0h calls to set up display context.
BE5Fh
Single Character Output (Extended)
DISPLAY
// INPUT
A = character code (see extended codes below)
D = row (0–3)
E = column (0–23)
// OUTPUT
None
// DESTROYS
AF BC HL
Extended character output supporting special symbols via codes 0x10–0x1F: 10h=空(blank), 11h=橋|1, 12h=橋|2, 13h=橋, 14h=<橋, 15h=^2, 16h=^3, 17h=~x, 18h=~y, and more. Also outputs standard ASCII when A ≥ 0x20.
BFEEh
Repeated Character Output
DISPLAY VERIFIED
// INPUT
A = ASCII character (e.g. 0x20 = space)
B = repeat count
D = row (0–3)
E = column (0–23)
// OUTPUT
C = scroll-up count
DE = position after last char
// DESTROYS
AF B HL
Outputs the same character B times starting at (D,E). To clear the entire screen: LD A,0x20 / LD B,96 / LD DE,0x0000 / CALL BFEEh (96 = 4 rows × 24 columns).
BFF1h
String Output
DISPLAY VERIFIED
// INPUT
B = character count
D = row (0–3)
E = column (0–23)
HL = address of string data
// OUTPUT
C = scroll-up count
DE = position after last char
HL = address after last byte read
// DESTROYS
AF B
Outputs B bytes from the address in HL starting at position (D,E). If the output wraps past column 23, the display scrolls up (BASIC PRINT behaviour). Scroll count is returned in C.
Used extensively in the game binary for score/title text. The string is raw ASCII bytes — not null-terminated. Byte count in B is mandatory.
BFD0h
Graphics Pattern Output (GPRINT)
DISPLAY VERIFIED
// INPUT
B = byte count
D = pixel column (0–143)
E = character row (0–3)
HL = address of pattern data
// OUTPUT
HL = address after last byte read
// DESTROYS
AF B E
Preserves: C D
Outputs B bytes of pixel pattern data at position (D, E). Each byte = 8 vertical pixels (bit 0 = topmost). D is the pixel column (0–143), E is the character row (0–3). The BIOS handles all controller routing and page commands internally.
IMPORTANT: BFD0h destroys DE and HL. The game binary always does PUSH DE / PUSH HL before calling and POP HL / POP DE after. Also destroys B (byte counter goes to 0). Called from BASIC via GPRINT command.
BFEBh
Clear Graphics Screen
DISPLAY
// INPUT
None
// OUTPUT
None
// DESTROYS
AF B HL
Preserves: C DE
Clears the graphics display area (equivalent to BASIC's CLG command). Zeros all pixel data on screen.
Note: IX is listed as not preserved (不定). Do not rely on IX after this call.
BE65h
Clear to End of Line / Right
DISPLAY
// INPUT
D = row (0–3)
E = column (0–23)
// OUTPUT
None
// DESTROYS
AF BC DE HL
Clears from position (D,E) to the end of that row (rightward).

Input Routines

BE53h
Get Key Code (No Wait)
INPUT VERIFIED
// INPUT
None
// OUTPUT
A = key code (0 if no key)
Cy = 1 if key is pressed
// DESTROYS
F (Cy only in output)
Preserves: B
Returns immediately with the current key state. If no key is pressed, A = 0 and carry is clear. Returns key code from the IOCS key table (see below).
Requires interrupts to be enabled (EI) to function correctly from machine language monitor. The BIOS key scan relies on the system timer interrupt to update the internal key buffer. Polling loop: CALL BE53h / OR A / JR Z, loop
BCFDh
Wait for Key Press
INPUT
// INPUT
None
// OUTPUT
A = key code of pressed key
// DESTROYS
F
Blocks until a key is pressed, then returns the key code in A. Equivalent to BASIC's INKEY$ with a wait loop built in.
BE56h
Key Code to ASCII Character
INPUT
// INPUT
A = key code (from BE53h)
// OUTPUT
A = ASCII character
// DESTROYS
F B
Converts a raw key code (as returned by BE53h) to the corresponding ASCII character. Respects CAPS lock state. Upper/lowercase depends on CAPS status.
BD09h
Input 2-digit Hex Value
INPUT
// INPUT
None
// OUTPUT
A = entered hex value (8-bit)
// DESTROYS
F BC DE HL IX IY
Waits for the user to type two hexadecimal digits and returns the resulting byte value in A.
BD0Fh
Input 4-digit Hex Value
INPUT
// INPUT
None
// OUTPUT
HL = entered hex value (16-bit)
// DESTROYS
A BC DE IX IY
Waits for the user to type four hexadecimal digits (e.g. for an address) and returns the 16-bit value in HL.

System Routines

0030h
Register Dump (RST 30h)
SYSTEM
// INPUT
None
// OUTPUT
None (displays on screen)
// DESTROYS
None
Invoked via RST 30h (opcode 0xF7). Displays all register values on screen — useful for debugging. Does not return to caller in the usual sense; returns to MON.
C110h
Power Off
SYSTEM
// INPUT
None
// OUTPUT
Does not return
// DESTROYS
N/A
Shuts the calculator off. The machine will restart from the BASIC prompt when the ON key is pressed.

System Work Area RAM

ADDRESSNAMEDESCRIPTION
779ChContrastLCD contrast value. Write here then OUT(40h, 0x80+val) to apply.
7901hCAPS/Kana lockBit 0 = always 1. Bit 1 = CAPS lock. Bit 2 = Kana lock. Writable.
790DhVRAM scroll startLower 4 bits × 8 = actual scroll pixel offset. Used by BIOS text scroll. Read to compensate graphics positioning.
7966hINKEY1Non-zero after INKEY$ if key pressed. Not ASCII — use INKEY2 for ASCII.
7E00hINKEY2ASCII value of last key pressed via INKEY$. Not reset on no-key — check INKEY1 first.
 
  ; Read current scroll offset to compensate graphics Y position
  get_scroll:
      ld   a, (790Dh)
      and  00Fh         ; lower 4 bits
      ld   b, a
      add  a, a
      add  a, a
      add  a, a         ; * 8 = pixel offset
      ret               ; A = actual display start line

  ; Reliable clear screen for ML programs:
  ; Scroll-reset both controllers first, then BIOS clear
  cls_full:
      ld   a, 0C0h
      out  (054h), a    ; left controller scroll reset
      out  (058h), a    ; right controller scroll reset
      ld   a, 020h      ; space
      ld   b, 096h      ; 4×24 = 96 chars
      ld   de, 00000h  ; row 0, col 0
      call 0BFEEh       ; fill with spaces
      ret
