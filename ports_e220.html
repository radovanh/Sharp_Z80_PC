PC-E220 I/O Port Reference

Complete Z80 I/O port map for the Sharp PC-E220 pocket computer (build 1991). The E220 uses a HD62202 + HD61203 dual-controller LCD scheme identical in spirit to the G815, but with a different port assignment — LCD commands go to 58h, not 54h. System ports cover keyboard, bank mapping, serial interface, timer, and interrupts. Source: Achim Flammenkamp's PC-E220 technical analysis at uni-bielefeld.de.

LCD Port Map PC-E220

ARCHITECTURE: The E220 display is 144×32 pixels, driven by a HD62202 (left panel) and HD61203 (right panel), each covering 72 columns. This is similar to the G815's dual-HD61203 scheme but uses port 58h for commands and 5Ah for data. The command encoding also differs: column and row are packed into a single byte as (column × 4) + row | 0x40.
PORTDIRNAMEDESCRIPTION
58h OUT LCD command Combined column + row address command. Encoding: (column × 4) + row | 0x40, where 0 ≤ column < 24 and 0 ≤ row < 4.
59h IN LCD busy flag Bit 7 = 1 → LCD controller is busy. Poll before sending commands if timing is critical. May return 0x80 permanently in emulators — do not poll during emulation.
5Ah OUT LCD data write Write one pixel byte (8 vertical pixels) at the current cursor position. Cursor auto-increments after each write. Bit 0 = topmost pixel.
5Bh IN LCD data read Read pixel byte at current cursor. Each byte = 8 vertical pixels. May be unreliable in emulators — use a shadow buffer for read-modify-write instead.
G815 vs E220: The G815 uses ports 54h/56h (left) and 58h/5Ah (right) as separate command/data pairs with a separate page command (0xB8+page) and column address (0x40+col). The E220 packs both into a single byte at port 58h: (col × 4) + row | 0x40. There is only one command port.

LCD Command Encoding

Unlike the G815/G850 which send page and column as separate commands, the E220 encodes both into a single byte. The column here is a character column (0–23), not a pixel column, and the row is a page (0–3, each 8 pixels tall). 

  ; E220 LCD cursor positioning formula:
  ;   cmd = (char_col * 4) + row | 0x40
  ;   0 <= char_col < 24   (character columns, 6 pixels each)
  ;   0 <= row < 4         (page/row band, 8 pixels each)

  ; Example: position at char_col=3, row=1 (pixels 8–15, column 18–23)
  ;   cmd = (3 * 4) + 1 | 0x40 = 0x40 | 0x0D = 0x4D

  lcd_goto:  ; B = char_col (0-23), C = row (0-3)
      ld   a, b
      add  a, a    ; col * 2
      add  a, a    ; col * 4
      add  a, c    ; + row
      or   040h    ; | 0x40
      out  (058h), a
      ret
CHARACTER vs PIXEL COLUMNS: The E220 LCD controller operates at character-column granularity. Each character column is 6 pixels wide (the 5×7 font plus 1 pixel gap), giving 24 × 6 = 144 pixels across. To address a specific pixel column, compute char_col = pixel_x / 6 — sub-character pixel addressing is not directly supported by the hardware cursor.

Pixel Byte Format

  One byte = 8 vertical pixels in one character column:

  Byte:  bit7  bit6  bit5  bit4  bit3  bit2  bit1  bit0
  Row:   Y+7   Y+6   Y+5   Y+4   Y+3   Y+2   Y+1   Y+0  ← topmost (smallest Y)

  The display has 4 pages (rows 0–3), each 8 pixels tall:
    page 0 → Y  0–7
    page 1 → Y  8–15
    page 2 → Y 16–23
    page 3 → Y 24–31

  LCD controller auto-increments char_col after each write to port 5Ah.
  To fill a full row (all 24 char columns, one page):
    OUT(58h, 0x40 + page)   ; position to char_col=0, row=page
    24× OUT(5Ah, data_byte)  ; auto-advance through columns

Sample LCD Routines

  ; cls_e220 -- clear entire 144×32 display
  ; Sets all pixels to 0. Destroys: A, B, C
  cls_e220:
      ld   c, 0             ; row (page) counter
  cls_row:
      ld   a, c
      or   040h             ; char_col=0, row=c → cmd = 0x40 + c
      out  (058h), a        ; position cursor at col 0, this row
      ld   b, 24            ; 24 character columns
  cls_col:
      xor  a
      out  (05Ah), a        ; write zero byte (8 blank pixels)
      djnz cls_col
      inc  c
      ld   a, c \ cp 4
      jr   nz, cls_row
      ret

  ; write_pattern -- output B bytes from HL at char_col=D, row=E
  ; Destroys: A, B, HL
  write_pattern:
      ld   a, d             ; char_col
      add  a, a \ add a, a  ; * 4
      add  a, e             ; + row
      or   040h
      out  (058h), a        ; set cursor
  wp_loop:
      ld   a, (hl)
      out  (05Ah), a        ; write pixel byte
      inc  hl
      djnz wp_loop
      ret
SHADOW BUFFER: Port 5Bh (pixel read) may return garbage in emulators — the same caveat as the G815's port 57h. For read-modify-write operations (setting individual pixels), maintain a 96-byte shadow buffer (24 columns × 4 rows) and modify shadow data before writing to hardware. 
  ; Shadow buffer: 96 bytes (24 char-cols × 4 rows)
  E220_VRAM  EQU  02000h   ; layout: E220_VRAM + row*24 + char_col

  ; Flush entire shadow buffer to hardware
  flush_vram:
      ld   hl, E220_VRAM
      ld   c, 0             ; row counter
  fv_row:
      ld   a, c \ or 040h
      out  (058h), a        ; set cursor to col 0, row c
      ld   b, 24
  fv_col:
      ld   a, (hl) \ inc hl
      out  (05Ah), a
      djnz fv_col
      inc  c \ ld a, c \ cp 4
      jr   nz, fv_row
      ret

Keyboard Ports 10h – 13h

The E220 keyboard is an 8×8 matrix (regular keys) plus an 8×2 matrix (function keys), scanned via two strobe ports. Port 13h provides the SHIFT key status independently.

PORTDIRNAMEDESCRIPTION
10h IN Key column read Returns column bitmask (bits 0–7) of the currently strobed row. Active-high: bit=1 means key pressed. Read after writing strobe to port 11h or 12h.
11h OUT 8×8 matrix row strobe Write a 1-bit mask to select one of 8 rows of the main key matrix. Values: 01h (row 0) … 80h (row 7). Write 0 to deselect.
12h OUT 8×2 function key strobe Selects one of 2 function-key rows via bits 0–1. Bit 0 = function row 0, bit 1 = function row 1. Read result from port 10h.
13h IN SHIFT key status Bit 0 = SHIFT key status (1 = pressed). Read independently of the matrix scan — no strobe needed. 
  ; Scan main key matrix — returns A=column bits, B=row bit if any key pressed
  ; Returns A=0, B=0 if no key pressed
  scan_keys:
      ld   b, 080h          ; start with row 7 (bit 7)
  sk_row:
      ld   a, b
      out  (011h), a         ; strobe row
      in   a, (010h)         ; read columns
      or   a
      jr   nz, sk_found      ; NZ = key pressed
      rrc  b                  ; next row
      jr   nc, sk_row         ; loop until all 8 rows done
      xor  a                  ; no key
      ret
  sk_found:                   ; A = column mask, B = row mask
      ret

  ; Check SHIFT key
  check_shift:
      in   a, (013h)
      and  001h             ; bit 0 = SHIFT
      ret                     ; NZ = shift pressed

Interrupt Ports 16h – 17h

PORTDIRNAMEBITSDESCRIPTION
16h I/O Interrupt flags bits 0–3 Read to query pending interrupts; write to clear them. Bit 0 = keyboard · Bit 1 = ON key · Bit 2 = timer · Bit 3 = CPU INT pin
17h OUT Interrupt enable bits 0–3 Enable/disable individual interrupt sources. Bit 0 = keyboard · Bit 1 = ON key · Bit 2 = timer · Bit 3 = CPU INT pin
Set bit to 1 to enable that source.
14h I/O Timer signal bit 0 Bit 0 = timer signal from LCD driver clock. Period ≈ 0.95 s. This is the LCD driver oscillator divided down — not a general-purpose timer.

ROM Bank Mapping PORT 19h

BANK ARCHITECTURE: The E220 has a 128 KB ROM organised as 8 × 16 KB banks (bank 0–7). Two separate 16 KB windows are mapped into Z80 address space: one at C000h–FFFFh and one at 8000h–BFFFh. Both windows are independently selectable via bits of port 19h.
PORTDIRBITSWINDOWDESCRIPTION
19h I/O bits 0–2 C000h–FFFFh Selects one of 8 internal ROM banks (0–7) for the upper window. Current value is also stored at RAM address 7900h.
19h I/O bit 6 8000h–BFFFh If bit 6 set, bits 4–5 address one of four 16 KB ROMs on the expansion port. Enables external ROM cartridge mapping into the lower 16 KB window.
1Bh OUT bit 2 0000h–7FFFh If bit 2 set, maps an external 32 KB RAM (expansion port) to 0000h–7FFFh. Cleared on BASIC module init. Do not set if no expansion RAM is attached.

  bank_basic:
      ld   a, 001h
      out  (019h), a

  ; Switch to assembler/monitor (bank 5)

Serial Interface Ports 15h / 18h / 1Fh

PORTDIRBITSDESCRIPTION
15h I/O bit 0, bit 7 Bit 0: cleared to enable XIN input. Bit 7: indicates XIN input enabled/inhibited. Controls the serial receive data path from pin XIN (11-pin interface pin 6).
18h I/O bits 0, 1, 7 Bit 0 = BUSY/CTS output (pin 4) · Bit 1 = DOUT output (pin 5) · Bit 7 = XOUT/TXD (complement of transmit bit, pin 7). Bit 7 is the serial transmit data: write the complement of each data bit here.
1Fh IN bits 0, 1, 2, 7 Bit 0 = DIN (pin 8) · Bit 1 = ACK/RTS (pin 9) · Bit 2 = XIN/RXD complement (pin 6) · Bit 7 = ON/break key status. XIN data bit is inverted — complement bit 2 when reading received serial data.
PROTOCOL: The serial interface uses Intel Hex format at up to 9600 baud. Signal levels are 0 V / 5 V (CMOS), not RS-232 ±12 V. A level converter is required to interface with a PC's RS-232 port. Allow at least 0.1 s after each Intel Hex line for the Sharp to decode the data.

Miscellaneous Ports

PORTDIRNAMEDESCRIPTION
1Ch OUT Peripheral reset Bit 0 = trigger status · Bit 1 = signal level (low or high). Used to reset peripheral devices on the expansion bus.
1Dh IN Battery status Bit 0 = battery OK (1 = OK, 0 = low battery warning).
1Ah OUT (unknown) Cleared during BASIC module initialisation. Do not write arbitrary values.
1Eh OUT (unknown) Bits 0–1 documented as used. Function not fully mapped.

11-Pin Interface 2.54mm HEADER

SIGNAL LEVELS: The E220 uses 0 V / 5 V CMOS logic, not RS-232. A level converter is required for PC interfacing. Input voltages significantly above 6 V may destroy the unit. The buzzer output (pin 1) is a direct TTL signal — suitable for driving a piezo buzzer without buffering.
