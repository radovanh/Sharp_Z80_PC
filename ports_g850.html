PC-G850 I/O Port Reference

Z80 I/O port map for LCD graphics on the Sharp PC-G850, PC-G850S, PC-G850V, and PC-G850VS. The G850 uses a single integrated LCD controller accessed entirely through port 40h, making it simpler than the G815's dual-controller scheme. Data from z88dk locate.asm, akiyan.com technical data, and the poke-com GPRINT documentation.

Port Map PC-G850 SERIES

ARCHITECTURE: The G850 uses a single controller. All commands — X address, Y page, scroll, contrast, display on/off — go through port 40h. Data is written and read back through port 42h/41h. Even/odd address mirrors exist across the 40h–6Fh range.
PORTDIRNAMEDESCRIPTION
40h OUT Command register All drawing commands: X address nibbles, Y page, scroll, contrast, display control. Also even-address mirrors: 42h, 44h … 6Eh are identical.
40h IN Status / command echo Reads back the last value written to 40h. Bit 7 = busy when set. Also odd-address mirrors: 41h, 43h … 6Fh.
42h OUT Pixel data write Write one pixel byte (8 vertical pixels) at the current GCURSOR position. GCURSOR auto-increments after each write. Even-address mirrors apply here too.
41h IN Pixel data read Read pixel byte at current GCURSOR. First read is dummy (primes latch), second returns data. Odd-address mirrors apply.

Command Reference PORT 40h

The upper nibble of the command byte selects the command class. The lower nibble carries the parameter.

VALUE RANGECOMMANDNOTES
00h – 0Fh GCURSOR X low nibble Lower 4 bits of X column address. Send this first.
10h – 1Fh GCURSOR X high nibble Upper 4 bits of X column address, OR'd with 10h. Send after low nibble.
24h LCD voltage OFF Turn display power off.
25h LCD voltage ON Turn display power on.
40h – 7Fh VRAM display start line Vertical scroll: 40h = line 0 (no scroll), 7Fh = line 63. 1-dot-per-step smooth scroll.
80h – 9Fh Contrast 80h = brightest, 9Fh = darkest.
A0h / A1h Mirror off / on A1h flips display horizontally.
A6h / A7h Invert off / on A7h inverts all pixels (black↔white).
B0h – B7h GCURSOR Y page Select 8-pixel row band. B0h = rows 0–7, B5h = rows 40–47 (max for 48-row display).
C0h – CFh Partial display modes Various partial-screen suppression modes. C0h = normal full display.

Command Sequence

  1. 1Reset scroll: OUT(40h, 40h) — sets display start line to 0
  2. 2Set Y page: OUT(40h, 0xB0 + (Y>>3)) — selects 8-pixel row band
  3. 3Set X low nibble: OUT(40h, X & 0x0F)
  4. 4Set X high nibble: OUT(40h, (X >> 4) | 0x10)
  5. 5Write pixel byte: OUT(42h, byte)
NOTE: On the G850, Y is set before X (opposite approach would also work since each command is independent), but the z88dk library sets Y page in sety() then X nibbles in setx(), and this order is confirmed to work correctly.

X Addressing — Two Nibbles

The G850 column address is 8 bits wide (0–143), sent as two 4-bit nibbles. Unlike the G815, there is no mirror — X=0 maps to the leftmost column, X=143 to the rightmost, with a single controller covering the full width. 

  ; Set GCURSOR X to column X (0-143)
  ; Send low nibble first, then high nibble | 0x10
  set_x:
      ld   a, h           ; H = X
      and  00Fh           ; low nibble (bits 3-0)
      out  (040h), a     ; OUT low nibble

      ld   a, h
      rra  \ rra \ rra \ rra  ; shift high nibble down
      and  00Fh
      or   010h           ; set class bit: 1x = high nibble command
      out  (040h), a     ; OUT high nibble | 0x10
EXAMPLE: X=100 (0x64): low nibble = 0x04 → OUT(40h, 04h). High nibble = 0x06 → OUT(40h, 16h).

Y Addressing — Page Command

CMD VALUEPAGEPIXEL ROWS
0xB000–7
0xB118–15
0xB2216–23

Formula: page_cmd = 0xB0 | (Y >> 3)  —  Note: the G850 uses 0xB0 base (not 0xB8 like the G815).

Pixel Byte Format

  One byte = 8 vertical pixels at the current GCURSOR column:

  Byte:  bit7  bit6  bit5  bit4  bit3  bit2  bit1  bit0
  Row:   Y+7   Y+6   Y+5   Y+4   Y+3   Y+2   Y+1   Y+0  ← topmost (smallest Y)

  To plot pixel at (X, Y):
    page      = Y >> 3                ; 0–5  (G850 has 6 pages)
    bit_index = Y & 7
    bit_mask  = 1 << bit_index
    page_cmd  = 0xB0 | page

  Read-modify-write sequence:
    OUT(40h, page_cmd)
    OUT(40h, X & 0Fh)       ; X low nibble
    OUT(40h, (X>>4)|10h)   ; X high nibble
    IN  A, (41h)             ; dummy read  (primes latch)
    IN  A, (41h)             ; real read   → existing byte
    OUT(40h, X & 0Fh)       ; re-issue X (prevents auto-increment corruption)
    OUT(40h, (X>>4)|10h)
    OR  bit_mask             ; set pixel
    OUT(42h, A)              ; write back

Startup Sequence

  1. 1Reset scroll: OUT(40h, 40h) — start line 0 (value 40h in range 40h–7Fh)
  2. 2Optionally set contrast: OUT(40h, 8Ch) — mid-range
  3. 3Clear screen via BIOS: CALL 0BFEEh with A=space, B=count, DE=0
  4. 4Begin drawing
  scroll_reset:
      ld   a, 040h         ; start line 0  (range 40h-7Fh, 40h = no scroll)
      out  (040h), a
      ret

Complete plot Routine

  ; plot_g850 -- set pixel at H=X (0-143), L=Y (0-47)
  ; Destroys: A, B, C
  plot_g850:
      ld   a, h \ cp 144 \ ret nc   ; bounds check X
      ld   a, l \ cp  48 \ ret nc   ; bounds check Y

      ; bit mask = 1 << (Y & 7)
      ld   a, l \ and 007h
      jr   z, pg_bit0
      ld   b, a \ ld a, 001h
  pg_shft: rlca \ djnz pg_shft \ jr pg_mask
  pg_bit0: ld a, 001h
  pg_mask: ld c, a                  ; C = bit mask

      ; Y page command
      ld   a, l \ srl a \ srl a \ srl a
      or   0B0h                     ; G850 page base = 0xB0
      out  (040h), a               ; SET Y

      ; X low nibble
      ld   a, h \ and 00Fh
      out  (040h), a               ; X low

      ; X high nibble
      ld   a, h \ rra \ rra \ rra \ rra
      and  00Fh \ or 010h
      out  (040h), a               ; X high | 0x10

      ; read-modify-write
      in   a, (041h)               ; dummy read
      in   a, (041h)               ; real read
      or   c                        ; set pixel bit
      ld   b, a                     ; save result

      ; re-issue X (reset auto-increment pointer)
      ld   a, h \ and 00Fh
      out  (040h), a
      ld   a, h \ rra \ rra \ rra \ rra
      and  00Fh \ or 010h
      out  (040h), a

      ld   a, b
      out  (042h), a               ; write back
      ret

  ; plot_clear_g850 -- clear pixel at H=X, L=Y
  plot_clear_g850:
      ; ... same as plot_g850 but AND ~bit_mask instead of OR
      ; replace "or c" with "cpl / and c / ld b,a" where c=mask
NOTE: On real G850 hardware, the IN A,(41h) read-modify-write works correctly. If porting from G815 code which uses a shadow buffer (because G815 readback is unreliable in the emulator), the shadow buffer approach also works on G850 and avoids the double-read requirement.
