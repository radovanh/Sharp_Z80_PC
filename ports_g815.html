Port Map PC-G815

CONFIRMED: Port 54h and port 58h both produce output. Port 55h and 59h (busy flags) return 0x80 indefinitely in the g800 emulator — do not poll them during emulation.
PORTDIRNAMEDESCRIPTION
LEFT CONTROLLER — covers X = 0–71 (left half of screen)
54h OUT Command register Send page command (0xB8–0xBF) then column address (0x40–0x7B). Also accepts scroll reset: 0xC0 → display start line 0.
55h IN Busy flag Bit 7 = 1 → controller busy. CAUTION Returns 0x80 permanently in g800 emulator. Do not poll in emulated code.
56h OUT Pixel data write Write one pixel byte (8 vertical pixels, bit 0 = topmost). Column address auto-increments after each write.
57h IN Pixel data read Read pixel byte at current address. First read is a dummy (primes latch). CAUTION Returns garbage in g800 emulator. Use shadow buffer for RMW instead.
RIGHT CONTROLLER — covers X = 72–143 (right half, mirrored)
58h OUT Command register Same encoding as port 54h. Page 0xBC–0xBF selects right-half pages 0–3. Col addr range: 0x40–0x4B (12 cols, X=72–83) and 0x40–0x7B (60 cols, X=84–143 via mirror).
59h IN Busy flag Bit 7 = busy. Same caution as port 55h applies.
5Ah OUT Pixel data write Write pixel byte to right controller. Auto-increments.
5Bh IN Pixel data read Dummy read then real read. Unreliable in emulator.

Column Geometry HARDWARE VERIFIED

KEY INSIGHT: The screen splits at X=72 (not X=60 as earlier documentation suggested). The right half is a mirror image — column addresses run right-to-left. Both halves use the same address range; the page command selects which half.
LOGICAL XPHYSICAL XPORT CMD/WRCOL ADDR FORMULAHALF
0 – 59 0 – 59 54h / 56h 0x40 + X left-left (LTR)
60 – 71 60 – 71 58h / 5Ah 0x40 + (X − 60) left-right (LTR)
72 – 131 71 – 12 54h / 56h 0x40 + (143 − X) right-left (RTL mirror)
132 – 143 11 – 0 58h / 5Ah 0x40 + (143 − X − 60) right-right (RTL mirror)

After computing the physical X, both halves use identical column address logic: if physical X < 60 use port 54h with col = 0x40 + phys_X; if physical X ≥ 60 use port 58h with col = 0x40 + (phys_X − 60).

Command Sequence

CRITICAL: Page command must be sent before the column address. Sending column first causes incorrect placement. This was confirmed from z88dk source code.
  1. 1Send scroll reset once at startup: OUT(54h, 0xC0) and OUT(58h, 0xC0)
  2. 2Compute physical X: mirror if X ≥ 72 (phys = 143−X)
  3. 3Select port: phys_X < 60 → port 54h/56h; phys_X ≥ 60 → port 58h/5Ah
  4. 4Send page command: left half: 0xB8 + (Y>>3); right half: 0xBC + (Y>>3)
  5. 5Send column address: 0x40 + phys_X (or 0x40 + (phys_X−60) for port 58h)
  6. 6Send pixel byte: OUT(wr_port, byte)

Page Command Encoding

The page command selects both the 8-pixel row band and which screen half. This is the key difference from single-controller displays.

VALUEHALFPAGEPIXEL ROWS
0xB8Left (X=0–71)00–7
0xB9Left (X=0–71)18–15
0xBALeft (X=0–71)216–23
0xBBLeft (X=0–71)324–31
0xBCRight (X=72–143)00–7
0xBDRight (X=72–143)18–15
0xBERight (X=72–143)216–23
0xBFRight (X=72–143)324–31

Formula: page_cmd = (X < 72 ? 0xB8 : 0xBC) | (Y >> 3)

Pixel Byte Format

  One byte = 8 vertical pixels at the current column address:

  Byte:  bit7  bit6  bit5  bit4  bit3  bit2  bit1  bit0
  Row:   Y+7   Y+6   Y+5   Y+4   Y+3   Y+2   Y+1   Y+0  ← topmost (smallest Y)

  To set pixel at (X, Y):
    page      = Y >> 3                ; 0–3
    bit_index = Y & 7                 ; 0 = top of page
    bit_mask  = 1 << bit_index

  To set:   byte = shadow[page*144+X] | bit_mask
  To clear: byte = shadow[page*144+X] & ~bit_mask

Shadow Buffer

WHY: Port 57h and 5Bh (pixel data read) return garbage in the g800 emulator. Without a shadow buffer, any pixel write would set all 8 pixels in that column to 0xFF (erasing neighbours).

Allocate 576 bytes at a fixed RAM address (e.g. 0x2000). Layout: PP_VRAM + page*144 + X. Zero it at startup. All pixel operations read from shadow, modify, write shadow, then send to hardware. 

  ; Shadow buffer layout (576 bytes from PP_VRAM)
  PP_VRAM      EQU 02000h    ; 144 cols × 4 pages = 576 bytes

  ; Address of shadow byte for pixel (X, Y):
  ;   addr = PP_VRAM + (Y>>3)*144 + X

  ; plot: set a pixel
  plot:
      call pp_setup       ; HL=shadow, C=mask, B=page cmd, D=phys_X
      ret  c              ; out of range
      ld   a, (hl)
      or   c              ; set bit
      ld   (hl), a
      call pp_send        ; OUT page, col, data
      ret

  ; plot_clear: clear a pixel
  plot_clear:
      call pp_setup
      ret  c
      ld   a, c
      cpl                 ; invert mask
      ld   c, a
      ld   a, (hl)
      and  c              ; clear bit
      ld   (hl), a
      call pp_send
      ret

Startup Sequence

  1. 1Clear the shadow buffer: zero all 576 bytes at PP_VRAM
  2. 2Reset scroll on both controllers: OUT(54h, 0xC0) then OUT(58h, 0xC0)
  3. 3Optionally clear the screen via BIOS: CALL 0xBE62h
  4. 4Begin drawing — no further initialisation required
  scroll_reset:
      ld   a, 0C0h
      out  (054h), a    ; left controller scroll reset
      out  (058h), a    ; right controller scroll reset
      ret

Complete plot Routine

  ; pp_setup -- compute shadow addr, bit mask, page cmd, phys col
  ; IN:  D=X (0-143), E=Y (0-31)
  ; OUT: HL=shadow byte, C=bit mask, B=page cmd, D=phys_X
  ;      Carry SET if out of range
  pp_setup:
      ld   a, d \ cp 144 \ scf \ ret nc
      ld   a, e \ cp  32 \ scf \ ret nc
      ; bit mask = 1 << (Y & 7)
      ld   a, e \ and 007h
      jr   z, ps_bit0
      ld   b, a \ ld a, 001h
  ps_shft: rlca \ djnz ps_shft \ jr ps_mask
  ps_bit0: ld a, 001h
  ps_mask: ld c, a          ; C = bit mask
      ; shadow address = PP_VRAM + page*144 + X
      ld   a, e \ srl a \ srl a \ srl a  ; A = page
      ld   b, a \ ld hl, PP_VRAM
      or   a \ jr z, ps_pg0
  ps_lp:  ld a,l \ add a,144 \ ld l,a
          jr nc,ps_nc \ inc h
  ps_nc:  djnz ps_lp
  ps_pg0: ld a,l \ add a,d \ ld l,a
          jr nc,ps_xnc \ inc h
  ps_xnc:                  ; HL = shadow byte
      ; page command and physical X
      ld   a, d \ cp 72
      jr   c, ps_left
      ; RIGHT HALF: page base 0xBC, mirror X
      ld   a, e \ srl a \ srl a \ srl a \ or 0BCh \ ld b, a
      ld   a, 143 \ sub d \ ld d, a  ; phys_X = 143-X
      or   a \ ret
  ps_left:
      ; LEFT HALF: page base 0xB8, X unchanged
      ld   a, e \ srl a \ srl a \ srl a \ or 0B8h \ ld b, a
      or   a \ ret   ; D = X = phys_X, carry clear

  ; pp_send -- send page, col, data to correct port
  ; IN: B=page cmd, D=phys_X (0-71), A=data byte
  pp_send:
      ld   e, a           ; save data
      ld   a, d \ cp 60
      jr   nc, ps_r58
      add  a, 040h \ ld d, a
      ld   a, b \ out (054h), a  ; page
      ld   a, d \ out (054h), a  ; col
      ld   a, e \ out (056h), a  ; data
      ret
  ps_r58: sub 60 \ add a, 040h \ ld d, a
      ld   a, b \ out (058h), a
      ld   a, d \ out (058h), a
      ld   a, e \ out (05Ah), a
      ret
