PC-G815 — Left Panel Controller COLUMNS 0–119

NOTE: The G815's left controller uses ports 54h–57h, not the same set as the right controller. Earlier documentation confused 0x57 (data read) with the busy port — the fu-sen gist confirms 0x55 is the busy flag.
PORT DIR FUNCTION NOTES
54h OUT Command / address register Page row:  0xB8 + page (page 0–3)
Column addr: 0x40 + col (col 0–59 per half)
Scroll line: 0xC0 + line (range 0xC0–0xFF)
55h IN Busy flagREVISED Bit 7 = 1 → controller busy. Poll until clear before any access.
Source: gist comment while (inp(0x55) & 0x80);
Previous tables incorrectly showed 0x57 as the busy port.
56h OUT Pixel data writeREVISED Write one byte (8 vertical pixels, bit 0 = top) to current cursor position.
Source: outp(0x56, byte) for each column byte.
Gist: "0x54 setting to 0x56 write, 0x57 read"
57h IN Pixel data readREVISED First read is a dummy (primes the HD61203 internal latch). Second read returns the actual byte at the current cursor position.
Re-issue column address via 54h after reading to prevent auto-increment.

PC-G815 — Right Panel Controller COLUMNS 120–143

PORTDIRFUNCTIONNOTES
58h OUT Command / address register Same encoding as left panel: page 0xB8+page, column 0x40+col, scroll 0xC0+line.
Source: outp(0x58, 0xB8+y) and outp(0x58, 0x40+x)
59h IN Busy flag Bit 7 = 1 → busy. Source: while (inp(0x59) & 0x80);
5Ah OUT Pixel data write Source: outp(0x5A, byte). "0x58 setting to 0x5A write, 0x5B read".
5Bh IN Pixel data read Dummy read + real read sequence required. Re-issue column after read.

PC-G815 — Column Geometry

Each controller drives two mirrored halves of the display. Column addressing runs outward from the centre-line of each panel, so the right half of every panel is addressed in reverse.

PC-E200 / PC-E220 SINGLE CONTROLLER · 144×32

PORTDIRFUNCTIONNOTES
58h OUT LCD command / address Column: col×4 + row | 0x40 (col 0–23, row 0–3)
Page/row select: value | 0xB8
Scroll start: value | 0xC0 (0xC0–0xFF)
Source: E220 ROM disassembly and char_out.txt
59h IN Busy flag Bit 7 = 1 → HD62202/HD61203 busy.
Visible in E220 ROM: tight in a,(59h) / and 80h / jr nz loops.
5Ah OUT Pixel data write Each byte = 8 vertical pixels, bit 0 = topmost.
Cursor auto-increments; re-issue column address to prevent corruption.
5Bh IN Pixel data read Two reads required: first is dummy (primes latch), second returns data.
Documented in Achim Breidenbach's PC-E220 port table.

PC-G850 Series SINGLE CONTROLLER · 144×48

ARCHITECTURE DIFFERENCE: The G850 uses a completely different LCD controller scheme. All commands share port 40h using a command-class encoding in the upper nibble. There is no separate busy port — the controller uses command echo (read back via 41h) and even/odd port mirrors.
PORTDIRFUNCTION
40h OUT LCD command register — all drawing commands Upper nibble selects command class:
VALUE RANGE COMMAND PARAMETER
00h – 1Fh Set GCURSOR X Column low/high nibble pair. Two consecutive writes set full X position.
24h / 25h LCD voltage off / on n=4 off, n=5 on.
40h – 7Fh VRAM display start line 0x40=line 0, 0x7F=line 63. Enables 1-dot-increment vertical smooth scroll.
80h – 9Fh Contrast 0x80 = brightest, 0x9F = darkest.
A0h / A1h Mirror mode off / on Horizontal display flip.
A6h / A7h Invert off / on Reverse pixel polarity across whole display.
B0h – B7h Set GCURSOR Y page Row = n×8 (8-dot granularity). G850 has 6 pages (rows 0–47).
C0h – CFh Partial display suppression n=0 cancel, n=1 left 16 cols, n=2 right 10+mode cols, n=3 left 32, etc.
PORTDIRFUNCTION
41h IN Command echo Reads back the last value written to 40h.
42h–6Eh
(even)		 OUT Mirrors of 40h The LCD driver ignores extra address bits. OUT(0x40+2n, cmd) is identical to OUT(0x40, cmd).
43h–6Fh
(odd)		 IN Mirrors of 41h (command echo)

Scroll Reset — All Models

MODELPORT(S)VALUEEFFECT
PC-G850 40h 0x40 Sets start line to 0 (minimum of 0x40–0x7F range).
PC-G815 54h + 58h 0xC0 Both panels reset. Source: outp(0x54,0xC0); outp(0x58,0xC0);
PC-E200/E220 58h 0xC0 Resets display start line for the single controller.

Read-Modify-Write Sequence

Applies to all E-series and G815 controllers (HD61203 / HD62202 family). Required to set individual pixels without erasing adjacent ones.

  1. 1 Wait until busy clears: poll INP(busy_port) until bit 7 = 0.
  2. 2 Send page command: OUT(cmd_port, 0xB8 + page) where page = Y ÷ 8.
  3. 3 Send column command: OUT(cmd_port, 0x40 + col).
  4. 4 Dummy read: INP(read_port) — result discarded. This primes the HD61203 internal data latch.
  5. 5 Real read: existing = INP(read_port).
  6. 6 Re-issue column command (resets auto-increment pointer to prevent write going to the wrong address).
  7. 7 Set pixel bit: new_byte = existing | (1 << (Y & 7)).
  8. 8 Write back: OUT(write_port, new_byte).

Pixel Byte Format

One byte covers 8 vertically stacked pixels in the current page column. Bit 0 is the topmost pixel (smallest Y within the page).

Byte: bit 7 bit 6 bit 5 bit 4 bit 3 bit 2 bit 1 bit 0 Row: Y+7 Y+6 Y+5 Y+4 Y+3 Y+2 Y+1 Y+0 ← topmost To set pixel at (X, Y): page = Y >> 3 bit_pos = Y & 7 mask = 1 << bit_pos new_byte = read_byte | mask

Startup Sequence

Always reset the scroll position before drawing. The BASIC interpreter and its ROM routines modify the scroll register, so pixel coordinates may be displaced if left in an unknown state.

G815 Z80 assembly:
ld a, 0C0h   ; scroll reset value
out (054h), a  ; reset left panel
out (058h), a  ; reset right panel
G850 Z80 assembly:
ld a, 040h   ; start line 0 (value 0x40 in range 0x40–0x7F)
out (040h), a  ; send to LCD command register
